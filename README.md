# Finance-Analysis
📊 Project Overview
This project is an interactive Financial Analysis Dashboard developed using Microsoft Power BI.

The dashboard provides real-time insights into financial transactions and helps analyze total transaction amount, transaction volume, average transaction value, fees, taxes, transaction status, transaction types, customer segments, gender, states, and monthly trends.

The main objective of this project is to transform raw financial transaction data into meaningful business insights and support data-driven decision-making.

🎯 Project Objectives
Analyze overall financial transaction performance
Track total transaction amount and transaction volume
Monitor average transaction value
Analyze total fees and taxes
Compare successful, failed, and pending transactions
Analyze different transaction types
Compare customer segments
Analyze state-wise transaction performance
Identify monthly transaction trends
Analyze transaction behavior by gender
Understand customer and merchant-level transaction patterns

The monthly trend visual shows changes in total transaction amount throughout the year.

High-performing months
Low-performing months
Monthly transaction patterns

2. Transaction Status Analysis

Transactions are categorized into:

Success
Failed

This helps monitor transaction performance and identify potential transaction issues.

3. Customer Segment Analysis

The dashboard compares transaction amounts across customer segments:

4. State-wise Analysis
